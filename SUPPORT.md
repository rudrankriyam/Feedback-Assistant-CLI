# Support

Use GitHub Issues for reproducible bugs and concrete feature requests.

Please include:

- macOS version
- Xcode command line tools version
- `xcfb version`
- the command you ran
- whether Feedback Assistant is signed in
- whether Terminal has Accessibility permission, if using `fill` or `submit`
- whether `xcfb web auth status` succeeds, if using experimental web commands
- whether the Apple Account is password-based or passkey-only, without sharing the account identifier

Do not include private Apple account identifiers, team IDs, unpublished feedback contents, session cookies, CSRF values, or attachments that contain confidential project data.
